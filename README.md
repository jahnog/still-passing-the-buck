# Still Passing the Buck

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jahnog/still-passing-the-buck/blob/master/Historical_CMPI_Extension.ipynb)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20651730.svg)](https://doi.org/10.5281/zenodo.20651730)

This repository is the replication package for *Still Passing the Buck:
Macroeconomic and Fiscal Performance of Argentine Administrations, 1853–2025*.
It extends the Classical Macroeconomic Pressure Index (CMPI) and the Fiscal
Pressure Index (FPI) of della Paolera, Irigoin & Bózzoli (2003) to all 41
Argentine national administrations on a single 173-year scoring frame, with
documented corrections for known distortions in modern Argentine statistics.
Inputs combine World Bank World Development Indicators, official Argentine
sources (INDEC, BCRA, Ministerio de Economía), and historical series from 1853.

**Paper:** *Still Passing the Buck: Macroeconomic and Fiscal Performance of
Argentine Administrations, 1853–2025* — [Zenodo](https://doi.org/10.5281/zenodo.20651730)
and [MPRA](https://mpra.ub.uni-muenchen.de/id/eprint/130511) (Paper No. 130511).
PDF in this repository: [`paper/output/still-passing-the-buck.pdf`](paper/output/still-passing-the-buck.pdf).

## Notebook

`Historical_CMPI_Extension.ipynb` builds the CMPI, FPI, and Overall Index
series and emits the tables and figures extracted into the paper.

Long-form Argentina indicators are generated by
`scripts/generate_indicators_wdi-argentina.py` from the World Bank WDI bulk zip,
World Bank API snapshots, INDEC price workbooks, and the BCRA com3500 series.
Outside a repository checkout, the notebook downloads missing inputs, portraits,
`scripts/cmpi_core.py`, `scripts/presidency_portraits.py`, and `pyproject.toml`
from the public S3 mirror
(`https://jnpublicdata.s3.us-east-1.amazonaws.com/still-passing-the-buck/`),
kept in sync with `make upload` (`scripts/upload_s3_notebook-data.py`).

## Data

All inputs are kept repo-local (via Git LFS) so the notebook reruns without live
network access. Folder layout and the download/generate inventory are in
[`data/README.md`](data/README.md); series lineage is in
[`data/argentina/README.md`](data/argentina/README.md).

- `data/raw/<provider>/` — downloaded source files
- `data/processed/<purpose>/` — generated notebook inputs
- `data/provided/` — curated inputs that are not regenerated from downloads
  (see [`data/README.md`](data/README.md))

## Reproduce

```bash
uv sync --locked    # create the exact environment from uv.lock

make verify         # offline end-to-end: tests + input/provenance validators + execution
make manifest       # refresh SHA256 manifest after intentional data/artifact changes
make verify-manifest
make reproduce      # full refresh: downloads -> generators -> validators -> tests -> execution
```

Makefile targets wrap the per-source `scripts/download_*.py` and
`scripts/generate_*.py` scripts documented in `data/README.md`. Successful
`make verify` plus `make paper` checks that extracted tables match the
manuscript. Data vintages are stamped under the notebook's Figure 0 from the
`.meta.json` sidecars; `data/file-manifest.json` records SHA256 hashes for
replication inputs and generated paper artifacts. Citable snapshots are tagged
and archived on Zenodo
([doi:10.5281/zenodo.20651730](https://doi.org/10.5281/zenodo.20651730)).

Export the executed notebook to PDF with `scripts/render_notebook_paper.py`
(see [`docs/paper-export.md`](docs/paper-export.md)).

## 2025 coverage and revisions

Complete annual observations are used for 2025, but recent national-account
values remain subject to source revisions. Every CMPI and FPI input is present;
the absence of a grade-`D` placeholder in
[`data/provided/data-quality-flags.csv`](data/provided/data-quality-flags.csv)
records coverage, not finality. The 2024–25 administration remains in office
through 10 December 2027, so the ranking through 2025 is an incomplete-term
result.

## Manuscript

The standalone paper lives in [`paper/`](paper/) (pandoc Markdown source,
BibTeX bibliography). `make paper` extracts every figure and ranking table
from the executed notebook and builds the publication PDF with
pandoc + XeLaTeX — see [`paper/README.md`](paper/README.md).
